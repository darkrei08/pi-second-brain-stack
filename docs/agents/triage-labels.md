# Triage labels

The local tracker uses the canonical Matt Pocock labels as status vocabulary.

| Canonical role | Label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Requires maintainer evaluation |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Fully specified for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation or decision |
| wontfix | wontfix | Intentionally not actioned |
